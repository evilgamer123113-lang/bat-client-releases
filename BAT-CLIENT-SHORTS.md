## 4. Recording Architecture & Critical Fixes Preserved

1. **No `gdigrab` (Win32 error 5):** Use offscreen `BrowserWindow` via `node_modules\electron\dist\electron.exe` serving assets over ephemeral `127.0.0.1` HTTP ports.
2. **DPI & Bitmap Size Lock:** In Chromium recorders capturing raw `1080×1920`, call `app.commandLine.appendSwitch("force-device-scale-factor", "1")` and `high-dpi-support=1` + `useContentSize: true`, and hook `HTMLCanvasElement.prototype.getContext` to force `{ preserveDrawingBuffer: true, alpha: true }` on WebGL.
3. **True `#000000` Jet Black (no gray wash):** All FFmpeg encodes MUST include:
   ```
   -vf scale=in_range=full:out_range=limited:out_color_matrix=bt709 -pix_fmt yuv420p -colorspace bt709 -color_primaries bt709 -color_trc bt709 -color_range tv
   ```
4. **Electron multi-window survival:** Register `app.on("window-all-closed", (e) => e.preventDefault());` so destroying one recording window does not abort loading the next window.
5. **Natural 1.0× Bat Pet Speed & Focus:** Dispatch `focus` and `bat-startup-complete`, set `backgroundThrottling: false`, `win.webContents.setFrameRate(30)`, and enable `__enableVirtualClock()` / `__stepClock(33.3333)`.
6. **Home Launch Stay-in-Place & Wardrobe Back-Side Showcase:** `home_live.mp4` stays on `Launching…` without jumping tabs; `wardrobe_live.mp4` pre-clicks `[data-camera="back"]` before capture and after equipping `Lightning Bolt`.
7. **Mod Menu Zero-Clipping HUD Frame:** `recordModMenu()` removes `hud-idle`, adds `hud-menu panel-open`, and uses `1360×800` (`1.70:1`, matching `1680×988` `mc_bg.png`) with `center/100% 100% no-repeat`.
