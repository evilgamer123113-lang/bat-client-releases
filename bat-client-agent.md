## 2026-10-18 — v76 Motion Blur

Native Java MotionBlur + MotionBlurMixin applies a GPU temporal accumulation pass after GameRenderer.renderWorld (world/hand), before HUD/crosshair/menus. One persistent RGBA8 history texture, fullscreen shader triangle and GPU texture copy; no CPU pixel readback or per-frame image upload. Decay is frame-rate independent. This costs GPU bandwidth while enabled; no guaranteed FPS gain. Zero strength bypasses drawing. Menus/pause/unfocus/disabled clear history; world changes, resizing and long frame gaps reseed. Texture released when inactive; shader/VAO/texture deleted on renderer close. Raw GL program, VAO, texture unit/binding, unpack buffer, framebuffer, blend/depth/cull/scissor and viewport state restored. Shader initialization failure safely disables effect for the session with a log warning. Strength and enabled state use existing persisted module/profile config and keybind manager toggle.
