About Bat Client

An independent Minecraft project by Raven. Here's what we build and where to find us.

Bat Client by Raven is our Minecraft Java launcher and companion Fabric mod. Our official website is batclient.xyz.

What is Bat Client?

Bat Client brings game profiles, mod loaders, performance tools and cosmetic features together in a Minecraft: Java Edition launcher. It gives players a place to manage their game and customize how they play.

The launcher and companion mod

The launcher manages Minecraft versions, profiles, accounts and game settings. The companion Fabric mod adds Bat Client's in-game menus, HUD editor and modules such as Zoom, Nametags and Block Indicator.

Both belong to the Bat Client project by Raven. Our companion mod is called the Bat Client mod; it is not the unrelated project named BatMod.

Bat Client is not BatMod

Bat Client at batclient.xyz and BatMod at batmod.com are different projects. Bat Client is not affiliated with, developed by, or endorsed by BatMod. Similar names do not mean the same software or team.

BatMUD is also a separate project and has no connection to Bat Client.

Official website and downloads

Use batclient.xyz as the starting point for our downloads and updates. You can find our public releases in the Bat Client releases repository and read release notes on the Changelog page.
