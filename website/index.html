The stuff that's actually different

Features (not a sales pitch)
01

Frames that don't drop mid-fight

Bat Client tunes chunk rendering and memory allocation so your FPS stays steady when everything happens at once, instead of tanking right when it matters. It adapts render distance to what your GPU is actually handling.

→
02

Input that goes straight to the game

We skip the extra processing steps between your mouse and the screen. The result is a more direct, more responsive feel in PvP — no added layers deciding to slow you down.

→
03

A HUD you actually set up your way

Move, resize, recolor, or hide every HUD element — keystrokes, armor, a reach counter. Drag and drop it where it works for you, or pull a preset from the community.

The full picture

Cracked + Premium Support

Play with a Microsoft account or go offline. Both modes are fully supported — no feature is locked behind premium.

Cracked Skins on Any Server

See your friends' custom skins on any vanilla offline-mode server, every version from 1.8 to 1.21.11 — no server plugins needed. A client-side agent injects them on join.

Auto-Updater

Updates download in the background and install themselves on restart. You never have to manually download a new version.

Multi-Language

Built-in English, Arabic, and French support. Switch languages instantly from the launcher header — no restart needed.

Smart Java Detection

Bat Client auto-detects or downloads the right Java version for your Minecraft version. No manual path setup.

Secure by Design

SHA-256 verified updates, no password collection, Microsoft OAuth only. Your credentials never touch our servers.

Modrinth Integration

Browse, install, update, and manage mods directly from the built-in Modrinth browser. No external tools needed.

Discord Rich Presence

Show your friends what server you're on, what version you're playing, and how long you've been in-game — all via Discord RPC.

Animated Capes

Launcher Console & Flight Log

Loadout Export & Import

RAM & First-Run Wizard
