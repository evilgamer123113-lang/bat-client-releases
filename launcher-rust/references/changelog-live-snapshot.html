Bat Client 2.2.97

Changelog

Every release and what changed — performance fixes, cracked-skin updates, and new features. The launcher auto-updates, so this page just tells you what you got.

2.2.97Oct 29, 2026Latest

Sodium opt-out and simpler mod removal

  • Honor Sodium removal and disable choices inside older Bat mod packages, preserving protected contents and an original backup.
  • Keep removed automatic mods from returning after an in-flight download, and save removal choices atomically.
  • Remove mods directly without a confirmation dialog, with duplicate-click and file-collision protection.
  • Keep Sodium add-ons disabled while Sodium is opted out; manual Install and Enable remain available.
2.2.96Oct 29, 2026

Storage cleanup and mod preferences

  • Automatically clean unused update extraction folders older than 24 hours while preserving active stages and update reports.
  • Remember removed or disabled Sodium and other automatic FPS mods across loadouts. Explicit installation can restore them.
  • Skip obsolete AggressiveOpts on Java 11 and newer without erasing custom JVM settings.
  • Exclude Technical Utilities from automatic downloads and updates; check suggested updates against the selected Minecraft version and loader.
  • Pause hidden and background skin/cape previews to avoid unnecessary launcher rendering.
2.2.95Oct 25, 2026

Launch compatibility and skin fixes

  • Custom garbage collectors now override the default G1 collector without causing conflicting JVM settings.
  • Known incompatible Kind's Crystal Optimizer 1.6.3 builds are safely disabled on Minecraft 1.21.11, with the original JAR preserved.
  • Updated skin profile handling for modern Authlib while preserving existing premium and server-provided textures.
  • Windows, macOS Intel, macOS Apple Silicon and Linux packages checked on native runners, including real legacy and modern Authlib profile tests.
2.2.94Oct 22, 2026

Java detection and launch reliability

  • Correct Java 17 and Java 21 detection, including matching installed runtimes and verified automatic installation.
  • Custom JVM arguments remain supported, with quoted paths and clear validation for invalid main-class or classpath entries.
  • Fixed the cosmetics agent's missing ASM dependency error and added verification of bundled and cached agent files.
  • Windows, macOS Intel, macOS Apple Silicon and Linux packages tested on native build runners.
2.2.93Oct 15, 2026

Windows, macOS & Linux

  • Windows installer and portable update, macOS Intel and Apple Silicon ZIPs, and a Linux x64 AppImage.
  • Java downloads match your operating system and processor, with SHA-256 verification.
  • Automatic updates select the matching platform package. macOS app and Linux AppImage updates keep a backup of the previous version.
  • Choose your operating system on the download page. macOS builds are ad-hoc signed and are not Apple-notarized.
2.2.92Sep 30, 2026

Reworked Microsoft sign-in & secure accounts

  • Brand-new Microsoft login — a hand-rolled OAuth 2.0 + PKCE flow replaces the old device-code method. Sign in happens right inside the launcher in a dedicated window; no more copying a code over to a browser tab.
  • Secure account storage — your Microsoft tokens are now stored encrypted on disk, and sessions refresh automatically and more safely.
  • Clearer sign-in errors — closing the login window, accounts that don't own Minecraft, and expired sessions are all explained instead of failing silently.
  • All the launch & download speed wins from 2.2.90 and 2.2.91 carry over.
2.2.91Sep 27, 2026

Faster launch & downloads (round 2)

  • Much faster warm launches — the launcher no longer re-hashes every already-downloaded asset file on each launch, so starting a cached version is near-instant.
  • Cached builds skip the network entirely when figuring out which Java to use — zero round-trips for versions you've already played.
  • FPS boost mods are now remembered per profile, so re-launching a modded version skips the Modrinth checks and starts immediately.
  • First-time downloads keep the high parallelism from 2.2.90 for the fastest possible install.
2.2.90Sep 27, 2026

Instant launch & faster downloads

  • Instant Launch — the game files for your selected profile (client jar, natives, libraries, assets) are now pre-downloaded in the background as soon as you pick a profile, so pressing Launch starts Minecraft almost immediately instead of sitting on a long first-time download.
  • Faster downloads — download parallelism raised to around 16 threads (previously 2) so any remaining download finishes much faster.
  • The background pre-download smoothly hands off the moment you press Launch, and finishes the job a normal launch would.
  • Subtle status line under the Launch button shows pre-download progress.
2.2.89Sep 19, 2026

Partner servers & home widgets polish

  • Launch into servers instantly — clicking a partner server on the home page now starts the game connected directly to that server.
  • Drag-to-slide news carousel — the home news widget now supports pointer drag with snap on release.
  • Removed the "View all / View more" buttons from both home widgets.
2.2.88Sep 19, 2026

Home dashboard redesign

  • Latest News widget — horizontal image carousel of Bat Client news and updates, pulled live from our servers.
  • Partner Server widget — FlashMC, CubeCraft, Mineplex, The Hive and BlockMC with online status and one-click copy of each server address.
  • Removed the old Flight Strip, Flight Log and "What's New" panels from the home tab.
2.2.87Sep 14, 2026

Cracked skins everywhere you play

  • Skin injector works on every version 1.8 → 1.21.11 — all patch releases, every engine: Fabric, vanilla, Forge 1.13+, NeoForge, and classic Forge 1.8–1.12.2.
  • Added class mappings for all legacy patch versions that previously had no data.
  • Classic Forge (srgobf) name resolution fixed so it no longer fails at launch.
2.2.86Sep 14, 2026

Update toast fix

  • The update-completed toast now uses a green success style and auto-dismisses after 4 seconds instead of staying on screen.
2.2.85Sep 14, 2026

Multiplayer cracked-skin injection

  • Custom skins render on cracked servers — Bat Client now fetches remote players' skins and injects them into your tab list so you actually see them.
  • Verified live on multiplayer; skins show for other cracked-mode players.
2.2.84Sep 13, 2026

Update pipeline verified end-to-end

  • Full ZIP self-update path validated live: chunked download, SHA-256 check, staged swap and relaunch all working.
2.2.83Sep 13, 2026

Updater crash fix

  • Fixed a bug that could stop the ZIP updater before it swapped files, leaving users stuck on an old version. If you're on 2.2.81 or earlier, grab the Setup installer once to hop back onto automatic updates.
2.2.82Sep 12, 2026

Launch reliability

  • Fixed a case where the launcher reported "launched" even when the game never started, hiding the real error.
  • Launcher log now shows the underlying error so failures are diagnosable.
2.2.81Sep 12, 2026

Version registry sync

  • In-place ZIP updates now sync the Windows uninstall registry entries so Control Panel shows the real installed version.
  • Removed duplicate uninstall keys left behind by older updates.
2.2.80Sep 12, 2026

Auth refresh handling

  • Fixed an authlib-injector debug flag that could crash launches.
  • Expired Microsoft sessions now show a clear "sign in again" message instead of failing silently.
2.2.79Sep 10, 2026

Skin diagnostics

  • Launches authlib-injector with debug logging so skin/profile requests can be traced when skins don't load.
2.2.78Sep 10, 2026

Update installation overhaul

  • Squash bugs in the ZIP updater's file-swap logic — updates now install reliably in place and relaunch correctly.
  • Signed texture properties now travel with session profiles, fixing skin loading for premium accounts.
2.2.65Sep 6, 2026

Update freeze fully fixed

  • SHA-256 verification is now streamed, so big updates no longer freeze the launcher window mid-download.
  • Builds on the async extraction and single-instance guard from 2.2.64.
2.2.64Sep 6, 2026

Stability release

  • Single-instance lock prevents multiple launcher copies from corrupting each other's files.
  • Zip extraction and update installs are now async — no more frozen window during updates.
  • Portable builds fixed so packaged updates extract correctly every time.
2.2.63Sep 2026

Launch fixes & hosted skin API

  • Fixed a startup hang caused by an asynchronous skin-upload race.
  • Hosted skin server went live — skins and capes stored and served from our own API.
